Guardrails

The agent drafts. People decide.

  • The agent's MCP server has no approve, send or delete tool. It physically cannot approve its own work. Safety lives in the tool list, not the prompt.
  • Self-review returns 409. Approving over a failing pre-check is refused too.
  • Traceability pre-check: every number traces to a client answer or is marked ≈ derived.
  • Client text is quoted data between fixed delimiters, never an instruction. Every output is schema-checked.

Local-first by construction

Nothing leaves the box. By code, not by promise.

  • Refuses to start if the model URL isn't loopback: a LocalOnlyError, not a comment in .env.
  • CSP default-src 'none': no fonts, no CDN, no telemetry. The console, and this deck, load nothing from the network.
  • Rules first: the pipeline runs with the model down. The local model adds polish; provenance is recorded on every artifact.
  • On stage: nvidia-smi busy, a blocked curl from the OpenShell sandbox, a cloud model URL rejected at startup.
